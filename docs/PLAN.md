# Багаж-мастер — дизайн и план

## Суть

Игрок сортирует багаж в аэропорту. Уровень — 1–3 минуты. Монеты с уровней тратятся на улучшения аэропорта, аэропорт приносит доход, пока игрока нет.

Цикл: **уровень → награда → улучшения → новый город → следующий уровень**.

## Уровень

- Чемоданы выезжают из туннеля слева и едут по ленте вправо.
- Внизу три тележки, у каждой рейс: цвет + код аэропорта (AER, KZN, LED...). Код дублирует цвет — для дальтоников.
- Тап или перетаскивание отправляет чемодан в тележку своего цвета. Полная тележка уезжает, на её место встаёт новая (возможно, другого цвета).
- Чемодан, который ни одна тележка не взяла, можно положить в **буфер** (6 слотов). Если чемодан доехал до конца ленты, он сам падает в буфер.
- **Буфер переполнен — поражение.** Цель уровня — отправить N рейсов.
- Быстрая сортировка подряд даёт комбо и бонусные монеты.

### Особый багаж (по одному новому типу на город)

| Тип | Механика |
|---|---|
| Закрытый «?» | Цвет виден только после сканера |
| Тяжёлый | Занимает 2 слота буфера |
| VIP ★ | ×3 монет, если отправлен быстро |
| Хрупкий | Не дольше 10 секунд в буфере |
| Переноска с питомцем | Только в специальную тележку |
| Подозрительный | Сначала рентген (мини-тап) |
| Перепутанная бирка | Нужно перевесить бирку |

### Бустеры

Магнит (сам раскладывает 5 чемоданов), Заморозка ленты (10 с), +Слот буфера, Микс (перемешать тележки).

## Мета-прогрессия

- Города: Москва → Сочи → Казань → Стамбул → Дубай → ... по 20–30 уровней, у каждого свой фон и новый тип багажа.
- Улучшения за монеты: грузчики (быстрее тележки), касса рейсов (+% монет), склад (лимит офлайн-дохода), декор.
- Офлайн-доход копится до лимита (4–8 ч), при входе можно забрать ×2 за рекламу.
- Лидерборд «Пассажиров обслужено». Ежедневный подарок, колесо удачи, задания дня.

## Монетизация

**Реклама за награду** (только по нажатию игрока):
второй шанс после проигрыша · множитель награды за уровень (×2/×3/×5) · ×2 офлайн-дохода · бесплатный бустер · колесо удачи · примерка скина.

**Межстраничная**: между уровнями, начиная с 4-го, не чаще раза в 90 секунд, не сразу после рекламы за награду, никогда посреди уровня.

**Баннер**: только на ПК.

**Покупки**:

| ID | Товар | Ориентир цены |
|---|---|---|
| `no_ads` | Отключить рекламу (межстраничная и баннер; за награду остаётся) | 199 ₽ |
| `starter_pack` | Стартовый набор, разово после 5–10 уровня: 2000 монет, бустеры, скин | 99 ₽ |
| `coins_small` | 2 500 монет | 79 ₽ |
| `coins_big` | 8 000 монет | 199 ₽ |
| `boosters_pack` | По 5 каждого бустера | 149 ₽ |

Игра проходится полностью бесплатно: деньги — за удобство и косметику.

**Экономика (стартовые значения)**: уровень 40–60 монет (+5% за город), бустер ~250 монет, рост цены улучшения ×1.15 за уровень.

## Технические решения

- Unity 6, шаблон Universal 2D, портрет 9:16 (на ПК — по центру с фоном по бокам).
- Арт под 1080×1920, 100 px на юнит, ортографическая камера size 9.6.
- Код площадок только за интерфейсами `Platform/`: `IPlatformService`, `IAdsService`, `IPurchaseService`, `ILeaderboardService`, `ISaveStorage`. Выбор реализации — по define-символу (`YANDEX_GAMES`, `RUSTORE`, `GOOGLE_PLAY`).
- Сохранения — JSON (JsonUtility), запись не чаще раза в 3 секунды (ограничение облака Яндекса), покупки пишутся сразу.
- Пауза (`GamePause`) — время и звук останавливаются во время рекламы и при потере фокуса (требование модерации).
